# API Gateway (REST vers gRPC)

Ajouter ou modifier une route REST de api-gateway (point d'entrée HTTP unique) : contrôleur command/query, guards, token interne propagé en métadonnée gRPC, client gRPC du microservice, mapping d'erreurs et FALLBACK_ACTIVATED (206), proxy WebSocket. À utiliser pour tout travail dans api-gateway/.
