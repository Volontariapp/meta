# Labels et relance de CI sur les PRs (pr-label.sh, pr-retrigger.sh)

Poser ou retirer des labels sur une liste de PRs (notify-discord, docker-and-e2e) et relancer leur CI par un commit vide, via les scripts scripts/pr-label.sh et scripts/pr-retrigger.sh (API REST, compatibles avec un vieux gh).
